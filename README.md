Map Zoom List — Elementor Widget
Widget Elementor con mappa interattiva Leaflet e lista laterale sincronizzata. Hover o click su un punto della lista: la mappa zooma sul marker corrispondente e apre il popup.
Nessuna API key. Nessun costo di utilizzo.

Requisiti

WordPress 6.0+
PHP 8.0+
Elementor (free)
Leaflet.js 1.9+ (caricato via CDN o localmente)


Installazione

Copia il file widget-map-zoom-list.php nel tuo plugin o nel child theme
Registra gli asset nel tuo functions.php (vedi sezione Assets)
Il widget apparirà nel pannello Elementor sotto la categoria custom
